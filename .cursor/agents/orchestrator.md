# Orchestrator Agent
## Description
This agent handles task orchestration, workflow management, and coordination of multiple agents or tasks.
## Trigger Terms
- orchestrator
- workflow
- coordination
- task management
## Anti-trigger
- Do not use for simple CRUD operations
- Do not use for UI-only tasks
- Do not use for database-only tasks

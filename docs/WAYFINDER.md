# Wayfinder

The **structural index of the repo** — a machine-navigable map from each domain
concept to its entry point, its decision record / trace, and how to extend it.
The temporal companion is [`REPO-CHANGE-INDEX.md`](./REPO-CHANGE-INDEX.md)
(_how it got here_).

When you start work in a domain, read the row's **Entry point** and
**ADR / trace** first. When you change a domain, update its row in the same
commit (and the change index).

## Conventions

- **`@repo/acl` is the single source of truth** for department slugs and
  restricted roles. `proxy.ts` (edge) and `dept-access.ts` (node) both import
  it — never redefine the ACL inline (the two copies had already drifted; the
  package makes drift structurally impossible).
- **Errors are the lingua franca** across auth, API, and data boundaries. Throw
  typed `AppError` subclasses; catch at the boundary. Don't throw plain `Error`.
- **Role strings are stringly-typed by history**; the `Role` type lives in
  `@repo/acl`. Prefer it over bare `string` in new code.

# Global Agent Onboarding & ECC Refactoring

This rule details onboarding procedures and visual refactoring constraints required by the ECC council.

## ECC Council Rules

1. **Continuous Learning:** Monitor log changes and updatelearned rules dynamically to refine agent interactions.
2. **Enterprise Agent Ops:** Coordinate multi-agent tasks via structured plans and clean exit check gates.
3. **Make Interfaces Feel Better:** Refactor dynamic user interfaces to match CSS glassmorphic parameters (opaque outlines, transparent backdrops, fluid layouts).
4. **Codebase Onboarding:** All new agents must run a code dependency scan before starting feature work.
